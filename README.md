# 生涯：绿茵世界（green-world）

一款确定性的足球生涯与俱乐部经营模拟游戏，世界横跨六大洲际联合会与多层级虚构联赛金字塔。使用 TypeScript + Vite 构建，**运行时零第三方依赖**，生产构建可直接从 `file://` 离线打开。

## 玩法

- **生涯模式**：从青训营起步，逐周出场、成长、转会、拿荣誉，一路踢到退役。
- **经理模式**：接手俱乐部，排兵布阵、管理财政与工资结构、冲击洲际资格，董事会会考核你的成绩。
- **世界结构**：六大洲、多级联赛金字塔、升降级、洲际杯与世界杯资格链，俱乐部与国家队两条线互不干扰。
- **确定性**：同一随机种子必然复现同一个世界，便于测试与回放。

## 本地运行

需要 Node.js 24.20 或更新版本。

```sh
npm ci
npm run ci
npm run dev
```

打开 Vite 打印的本地地址即可试玩。生成离线版执行 `npm run build`，然后直接打开 `dist/index.html`；生成单文件 H5 包执行 `npm run build:single`。

## 目录结构

- `src/`：模拟规则、存档系统与界面
- `assets/`：美术清单（manifest）与打包的 WebP 素材
- `tests/`：单元测试与 DOM 级测试
- `docs/`：架构、注册表、工具链与截图说明
- `scripts/`：构建、校验与冒烟脚本

游戏内的俱乐部与球员均为虚构，不含任何真实俱乐部数据库。

## 质量与校验

- **271 项自动化断言 / 15 个 Vitest spec**，覆盖规则层（赛程、赛果、升降级、资格链、经济、存档）与界面动作分发。
- `npm run smoke:static` 校验静态构建约束（大小预算、图片不内联、无运行时拉取资源等）。
- 完整的浏览器冒烟与移动端检查需要可用的本地浏览器，缺失时会跳过并返回专用退出码。

体积预算（构建产物代码合计）：app.js ≤ 197 KB、合计 ≤ 207 KB、gzip ≤ 64 KB。
